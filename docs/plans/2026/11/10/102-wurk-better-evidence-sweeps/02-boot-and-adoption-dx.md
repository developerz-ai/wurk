# 02 — Boot, embed, and adoption DX

> Part of [`overview.md`](overview.md). Depends on: none (B1 breaking part waits on [`12`](12-human-decisions.md) H1).

Evidence = 5 adopter apps (sales, tesote.com, gringotts, hiscore.ro, legaldiligencemedellin) + treasury (read-only, not yet migrated). Every row was hit by ≥2 apps unless noted. Goal: delete the boilerplate each app re-invented.

## Done when
- A fresh Rails app + `gem "wurk"` needs zero of: `WURK_DISABLED` belt-and-braces, engine/adapter requires, read-timeout override, sizing module — each either fixed or logged with an actionable line.
- `wurk boot-check` in CI would have caught all four recorded prod boot crash-loops (each reproduced as a test fixture).
- `wurk preflight --app` on a treasury-shaped fixture flags: ms timestamps, `connection_pool` pin, `sidekiq` start command, `ps` probe, untested plugins.
