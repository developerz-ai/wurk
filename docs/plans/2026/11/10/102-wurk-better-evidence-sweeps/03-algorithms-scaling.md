# 03 — Algorithms + scaling cliffs

> Part of [`overview.md`](overview.md). Depends on: [`09`](09-proof-harness.md) T3 (scale benches) for before/after numbers; [`01`](01-correctness.md) R1 before A2 (same files).

Source: algorithms sweep (static read, nothing executed — every cost below is read from code; sizes are extrapolations until T3 measures them). Dimensions: Q queues, P processes, C concurrency, N jobs in a set, K periodic loops. **Wire rule: only which commands touch existing keys may change. No key, job JSON field, or score format moves.** A row whose fix would need one is dropped, not bent.

## Steps
1. T3 benches land first ([`09`](09-proof-harness.md)); record baseline numbers in the PR body of each A-row ("a performance claim names its bench").
2. PR sequence (one in flight): A1 → A2 → A4+A5 → A3 → A6 → A7+A8 → A9+A10 → A11 → A12/A13/A14 as measured.
3. A1, A2, A3, A7 touch fetch/reclaim/enqueue: run `bin/rake bench` before/after and `bin/rake test:parity`.
4. New/changed Lua lives in `lib/wurk/lua/*.lua`, loaded once via `Wurk::Lua::Loader` (EVALSHA + NOSCRIPT recovery). Declare every key in `KEYS` (cluster/Dragonfly safety — see the `--!df` note on `reliable_schedule_promote`).
5. `bin/repin-anchors` per PR.

## Tests
- A1: integration — queue of 50k with concurrent `LPUSH` + consumer thread; delete by jid/class removes all pre-existing matches, returns same shape as before; max single-script time bounded (assert via `SLOWLOG`-free approach: count of script calls ≥ N/1000).
- A2: integration — `kill -9` a swarm child; job reclaimed ≤2s; `CommandSpy` sees zero `SCAN` on respawn. Existing orphan-reclaim tests green.
- A3: integration — C≥Q idle fetchers; push to queue k; pickup latency < 250ms for every k. Unit: strict ordering preserved under load.
- A4: `CommandSpy` — registering K=200 loops issues O(K) commands.
- A5: property test — 10k random (schedule, tz, from) triples: new == stepping oracle; includes DST transitions, Feb 29, `0 0 1 1 *`.
- A6: `CommandSpy` — 2 round trips per limited job; stats hash fields unchanged (parity oracle if one exists for limiter stats).
- A7/A8: integration at 10k entries — all promoted/retried exactly once; round trips ≤ N/50.
- A9: unit — `info` bytes identical to pre-change for same state; 1 round trip per beat.
- A12: χ² distribution test vs `shuffle.uniq`.
