# docs/plans

Execution plans written by `/planx` and run by `/plan-exec`, one directory per plan: `docs/plans/<YYYY>/<MM>/<DD>/<1NN>-<slug>/`.

**This repository is public, so every plan here is a public document.** A plan describes changes to this repository. A slice that changes or measures another repository — an adopter's app, a deployment, the infrastructure — keeps its detail there and only its title and status here. Adopters are named A, B, C…, never by name.
